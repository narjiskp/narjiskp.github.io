# narjiskp.github.io
Bird Articles Website Summary  (Users perspective)

BY: NARJIS P

This website is about birds like cockatiels, parakeets, and lovebirds. The website has articles that tell basic information about each bird. It is made for people who want to learn about these types of birds or are thinking about getting one.

Bird Articles Website Summary (Developer’s Perspective)

When you go on the website, you start on the homepage. The homepage shows the names of the birds and links to their pages. When you click on a bird, it takes you to a page that talks about that bird and the six pillars:

1. General care and habitat
2. Specialized diet
3. Lifespan
4. Unique personalities 
5. Do they make a good pet?
6. Fun facts
